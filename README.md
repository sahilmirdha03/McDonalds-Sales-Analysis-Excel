# McDonald's Sales Analysis

## 📊 Project Overview

This project analyzes McDonald's sales data using Microsoft Excel to identify key sales trends, menu-item performance, order behavior, and category-wise revenue.

The project combines data cleaning, transformation, data modeling, Pivot Tables, Pivot Charts, and an interactive Excel dashboard to turn raw transactional data into meaningful business insights.

---

## 🎯 Project Objective

The main objective of this project is to analyze McDonald's sales data and answer key business questions related to:

- Revenue performance
- Order volume
- Menu-item popularity
- Category-wise sales
- Monthly sales trends
- Average items per order
- Order volume by time of day
- Weekday sales patterns
- Top-performing menu items

## 🔄 Data Analysis Workflow

1. Imported the McDonald's sales dataset
2. Cleaned and transformed the data using Power Query
3. Prepared the data for analysis
4. Built the data model using Power Pivot
5. Created Pivot Tables for the required business questions
6. Created Pivot Charts for visual analysis
7. Added slicers and timeline filters
8. Designed an interactive Excel dashboard
9. Extracted key findings and business insights

---

## 📌 Key Business Questions

The analysis answers the following questions:

1. What is the total sales revenue for each category of menu items?
2. How many orders are placed each day?
3. Which menu item is the most frequently ordered?
4. What is the total revenue generated by menu items?
5. How does the revenue of each category compare over months?
6. What is the average number of items per order?
7. How do order volumes vary by time of day?
8. How do sales trends differ across weekdays and weekends?
9. How does sales performance vary by category over different months?
10. What are the sales of the top 5 menu items?
